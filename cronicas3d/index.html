Cronicas3D

Interface Web experimental para transformar imagens de objetos do jogo em modelos 3D e preparar exportação em .GLB.

Beta Web 0.1 • GitHub Pages

Gerar objeto 3D

1

Prepare uma imagem do objeto com fundo limpo ou transparente. Para as tendas, prefira uma vista frontal/3⁄4 semelhante à câmera do mapa.

2

Abra o TRELLIS.2, envie a imagem e gere o modelo. No celular, mantenha a aba aberta durante o processamento.

3

Quando o modelo estiver pronto, use a opção de extração/exportação para GLB.

4

Envie o arquivo .glb aqui no ChatGPT para eu analisar escala, materiais, polígonos e adaptação ao Godot.

Abrir TRELLIS.2

Presets recomendados para o jogo

Tendas / ConstruçõesTextura 2048. Gerar com detalhe alto; depois otimizar a malha para uso no jogo.
Árvores / RochasTextura 1024 ou 2048. Priorizar silhueta e leitura visual em câmera distante.
Objetos pequenosTextura 1024. Meta de poucos polígonos após otimização.
Modelo mestreGuardar uma versão de maior qualidade e derivar uma versão leve para Godot/Web.
