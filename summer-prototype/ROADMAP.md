# Roadmap de produção — Crônicas da Promessa

## Filosofia

O desenvolvimento passa a seguir milestones jogáveis completos, validados pelo Summer/Codex, em vez de microfeatures isoladas.

## M1 — Primeiro Dia em Judá
Status: concluído.
- base jogável;
- Q1–Q9;
- interiores;
- necessidades;
- save local/autosave/portable;
- conclusão do primeiro capítulo.

## M2 — Data-Driven Game Framework
Status: concluído.
- ContentDatabase;
- itens, NPCs, schedules e quests orientados a dados;
- relações/reputação;
- diálogos contextuais;
- eventos;
- locations;
- Save Schema 2;
- conteúdo jogável do Dia 2.

## M3 — Mundo Vivo de Judá / Semana 1
Status: próximo milestone.
- sete dias completos;
- 12+ NPCs;
- vocação;
- crafting/produção;
- economia comunitária;
- relações/eventos;
- 20+ entradas de progressão;
- Save Schema 3;
- anti-softlock;
- mobile readiness.

## M4 — Expansão territorial
Planejado.
- mapa geral do acampamento e arredores;
- preparação para as 12 tribos;
- viagens entre áreas;
- mais vocações;
- eventos narrativos maiores;
- integração massiva dos assets pixel art aprovados.

## M5 — Campanha / Capítulos
Planejado.
- arco narrativo maior;
- eventos bíblicos definidos pelo projeto;
- progressão de longo prazo;
- múltiplas semanas/locais;
- balanceamento;
- polimento;
- builds PC/Android.

## Frente visual paralela

O desenvolvimento visual ocorre em paralelo e deve produzir assets substituíveis sem alterar a lógica:
- tilesets;
- personagens;
- NPC sprites;
- interiores;
- UI;
- mapas;
- animações;
- efeitos.

A integração visual deve respeitar a camada de referências criada pela arquitetura data-driven.
